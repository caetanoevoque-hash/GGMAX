# GGMAX — Pesquisa de Produtos e Análise de Concorrência

Pesquisa feita em 28/09/2026 a partir de anúncios públicos da GGMAX (via índice do Google, já que o site bloqueia acesso automatizado com Cloudflare), preços oficiais dos serviços e reclamações públicas no Reclame Aqui.

Arquivos:

- `analise-concorrencia.md` — relatório completo (tarifas, mercado, concorrentes, preços, riscos, oportunidades e estratégia de entrada)
- `dados/concorrentes.csv` — tabela bruta dos anúncios coletados
- `probe.py` — script de sondagem (Playwright) usado para tentar acessar as listagens; documenta o bloqueio da Cloudflare
